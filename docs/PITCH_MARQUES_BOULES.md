# Ultimate Petanque — Pour les Marques de Boules

**Obut, MS Petanque, La Boule Bleue, KTK, La Franc, Boulenciel, Marathon, Oddeka...**

**Vos boules dans les mains de milliers de joueurs. Nous mesurons leur impact.**

---

## Le probleme que nous resolvons pour vous

Aujourd'hui, vous vendez des boules, mais vous n'avez aucune donnee sur leur utilisation reelle en situation de jeu. Quels modeles performent le mieux au tir ? Au point ? Quels joueurs preferent vos produits ? Dans quelles regions etes-vous le plus populaire ?

**Ultimate Petanque** collecte ces donnees naturellement : chaque joueur enregistre ses matchs, ses defis et associe son jeu de boules. Nous compilons ces statistiques et les rendons accessibles.

---

## Ce que l'application offre a votre marque

### 1. Classement des boules par marque (deja actif)
L'application compile les statistiques de tous les joueurs publics par marque et modele :
- **Taux de victoire** des joueurs utilisant vos boules
- **Taux de reussite au tir** et **au point**
- **Nombre de carreaux** par modele
- **Popularite** : combien de joueurs utilisent chaque modele
- **Filtres par role** (tireur, pointeur, milieu) pour des comparaisons pertinentes

**Resultat :** Les joueurs consultent ce classement pour choisir leurs boules. Votre marque apparait dans un contexte de decision d'achat.

### 2. Programme Partenaire : 3 niveaux de visibilite

#### Bronze (sur devis)
- **Fiche partenaire** dans la page "Nos Partenaires"
- **Badge Bronze** sur votre profil
- **Marqueur personnalise** sur la carte interactive (couleur de votre marque)
- **Statistiques de base** : impressions et clics

#### Argent (sur devis)
- Tout Bronze +
- **Banniere rotative** sur l'ecran d'accueil (rotation 5s, vu par tous les joueurs)
- **1 notification push par mois** envoyee a tous les joueurs
- **Dashboard analytique complet** : impressions, clics, CTR, portee
- **Templates push pre-rediges** en FR/EN (7 categories)
- **Export CSV/PDF** de vos statistiques

#### Or (sur devis)
- Tout Argent +
- **Banniere permanente** en position prioritaire
- **Push notifications illimitees** avec A/B testing et ciblage geographique
- **Heatmap de performance** : meilleurs jours et heures pour vos campagnes
- **Calculateur ROI** avec projections annuelles
- **CRM integre** : suivi de vos parrainages avec export
- **Kit de marque** : logo, couleurs, banniere exportables
- **Digest hebdomadaire** automatique chaque lundi avec bilan complet
- **Section onboarding** : visibilite aupres de chaque nouveau joueur

### 3. Page publique dediee
Chaque partenaire dispose d'une page landing dans l'application :
- **Hero section** avec votre logo agrandi et couleur de marque en gradient
- **Compteurs animes** : impressions, clics, CTR, portee
- **Timeline d'activite** recente
- **Evenements sponsorises** que vous organisez
- **QR code personnalise** aux couleurs de votre marque pour vos supports marketing
- **Lien direct** vers votre site web

## Donnees collectees sur vos produits

Les joueurs enregistrent volontairement leur equipement. Voici ce que nous mesurons :

| Donnee | Description |
|---|---|
| Marque et modele | Identification precise du jeu de boules |
| Matchs joues | Nombre de matchs avec cet equipement |
| Taux de victoire | % de matchs gagnes |
| Tir : taux de reussite | % de tirs reussis |
| Point : taux de reussite | % de points reussis |
| Carreaux | Nombre total de carreaux |
| Type de joueur | Tireur, pointeur ou milieu |
| Terrain associe | Type de terrain (gravier, sable, bitume) |
| Zone geographique | Ville et pays du joueur |

**Toutes les donnees sont anonymisees.** Aucune information personnelle n'est partagee.
